# EEG_STM32

Модуль быстрой оцифровки аналоговых сигналов на STM32F446RET6 с передачей данных по UART. Предназначен для оцифровки любых других аналоговых сигналов c заданной частотой дискретизации.

## Функционал

- Высокоскоростная оцифровка через встроенный АЦП с передачей по DMA
- Частота дискретизации контролируется таймером — по событию таймера запускается АЦП
- Непрерывная передача оцифрованных данных по UART на ПК

## Принцип работы

Таймер генерирует события с заданной частотой. Каждое событие запускает преобразование АЦП. Результаты через DMA попадают в буфер без участия процессора и отправляются по UART.

## Аппаратная часть

- MCU: STM32F446RET6
- Плата спаяна вручную на макетной плате

## Стек

C, STM32F446, CMSIS/HAL, ADC, DMA, таймеры, UART

## Сборка

Проект собирается в STM32CubeIDE.
